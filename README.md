# abelhaKut

Versão funcional com status online/offline real.

## Esta versão inclui

- Login e cadastro com Firebase
- Sistema de amizades
- Chat em tempo real
- Notificações de mensagens
- Status online/offline nos amigos
- Status online/offline no cabeçalho do chat
- Barra lateral inferior direita avisando quando amigo entra ou sai
- Animação da notificação ficando transparente até sumir
