# abelhaKut

Rede social em HTML, CSS, JavaScript e Firebase.

## Estrutura

```text
index.html
css/style.css
js/app.js
assets/
```

## Funções atuais

- Login e cadastro com Firebase
- Confirmação de e-mail
- Recuperação de senha
- Foto de perfil
- Sistema de amizade
- Notificações
- Chat em tempo real
- Emoji picker
- Remover amizade
- Chat flutuante
